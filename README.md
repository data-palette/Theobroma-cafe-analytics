# Theobroma Cafe Analytics Pipeline & Dashboard

**Live Interactive Demo:** [View Live Streamlit Dashboard](https://theobroma-cafe-analytics-qure3asxkeptnk2yjujgnh.streamlit.app/)

An end-to-end telemetry and business intelligence pipeline designed for **Theobroma Cafe**. This project generates mock daily transaction data, transforms and loads it into a relational SQLite database using SQL aggregations, and visualizes real-time metrics through an interactive Streamlit web application formatted in Indian Rupees (₹).

---

## Architecture & Tech Stack

* **Language:** Python 3.x
* **Data Processing:** `pandas`
* **Database:** SQLite3
* **Visualization/UI:** Streamlit
